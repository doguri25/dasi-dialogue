# 참고 자료와 적용 범위

이 앱은 충청남도 관계회복 운영 자료를 참고해 만든 가상 대화 연습 도구다. 공식 서비스·공인 연수·실제 사건 판정 도구가 아니다. 사례, 학생 이름, 신청서 문구와 대화는 창작이며 실제 학생 기록을 포함하지 않는다.

- [충남 2026 신청서식](https://talkcne.or.kr/bbs/board.php?bo_table=notice&wr_id=102)
- [충남 관계회복지원단 안내](https://talkcne.or.kr/bbs/board.php?bo_table=notice&wr_id=81)
- [보관된 2026 길라잡이](https://drive.google.com/file/d/1ONfMRtLMJSnKZW4F-Ff4NSQOqHpuvF6A/view)
- [2026 결과보고서 양식](https://drive.google.com/file/d/16wsy0OMtfqL-8_smAU_-ExJ_SuHggTS6/view)

개인 Google Drive·Craft 조사 원문과 상위 폴더의 연구 노트는 소스 저장소에 포함하지 않는다. 연결 문서의 열람 권한은 각 제공처에 따라 다르며, 모든 첨부파일을 이 버전에서 재확인했다는 뜻은 아니다. 학생의 자발성, 중단과 보호, 사건의 영향, 필요한 도움, 책임 행동과 사후 이행을 연습 방향으로 사용한다.

가상 인물·상황 그림은 AI 생성 자산이며 [image-assets.json](image-assets.json)에 프롬프트와 생성 파일명을 기록했다. 학교급별 캐릭터와 주제 삽화를 여러 사례에 재사용한다.
