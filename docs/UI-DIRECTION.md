# 읽기 쉽고 누르기 쉬운 대화 연습실

대상은 디지털 기기에 익숙하지 않은 관계회복지원단 교사. 사용자가 요청한 큰 글자, 채워진 면, 부드러운 동작과 기기별 화면을 우선한다.

색: 바탕 #f3f5f8, 글자 #203b37, 초록 #235b4e, 연초록 #e3efde, 연보라 #ece8f7, 살구 #ffeadb. 선 대신 색 면과 간격으로 구획한다. 선택된 질문은 진한 초록 면, 체크와 ‘선택됨’ 글자로 표시한다.

글자: 한국어 시스템 고딕 하나로 통일. 본문 18px, 대화 19px, 제목 26–44px, 보조 정보도 14px 이상. 기본 두께 500, 제목·버튼 700 이상. 글자 크게 기능은 상대 단위로 전체를 확대한다. 읽기와 클릭에 필요한 문장은 왼쪽 정렬.

PC: 왼쪽 메뉴 / 대화창 / 답변 예시를 나란히 둔다. 대화 화면을 창 높이에 맞추고 보내기 버튼을 항상 보이게 한다. 진행 메모는 오른쪽 예시 영역과 전환하며 기록·종료 기능은 제목 옆에 둔다.

모바일·태블릿: 아래쪽에 이름이 있는 고정 탐색. 연습 안에서는 ‘대화 연습 / 진행 확인’을 나눠 한 가지 일에 집중한다. 질문은 1열, 대화와 입력은 같은 화면 흐름에 배치하고 진행 확인을 마치면 대화로 돌아온다. 글자 확대·AI 설정은 상단에서 접근한다.

초기 계획을 검토하여 단순히 모든 카드를 둥글게만 만드는 방향 대신, 관계회복 모임의 생성 삽화·참여자별 말풍선·선택할 발문에 색을 집중한다. 화면 크기를 줄이는 것에 그치지 않고 모바일의 진행 메모 위치와 탐색 방식을 바꾼다.

움직임은 사람의 조작에 답한다. 버튼 누름, 선택 표시, 창 열기, 새로운 발화, 단계 변경만 짧고 부드럽게 움직인다. 입력 중 전체 화면이 다시 움직이지 않도록 변경 범위를 구별하며 운영체제의 동작 줄이기를 따른다. 키보드 초점은 선으로 명확히 남긴다.

신청서는 읽은 뒤 버튼 하나로 사전모임에 이동한다. 추가 체크나 검토 선택 없이 PC·모바일 모두 문서를 한 흐름으로 보여 준다. 사전모임에서는 ‘대화모임 안내 → 무슨 일이 있었니?’ 두 순서를 큰 색 면으로 표시한다. 학생마다 순서를 따로 기억하고, 안내를 보낸 뒤에는 경험을 듣는 질문으로 바뀐다. 학생 얼굴은 학교급별 2명, 주제 삽화는 7종을 재사용하며 역할과 외모를 고정하지 않는다.

## v0.2 고도화

첫 화면은 가상 대화 삽화와 이어갈 연습을 중심으로 배치한다. 연습에서는 현재 저장 상태, 전체 대화 열기, 다음 단계에 필요한 확인 항목을 눈에 띄는 면으로 연결한다. 모바일은 진행 확인 열기로 필요한 위치까지 이동한다. 회고는 실제 질문 장면을 읽고 다음 발문을 생각하도록 구성한다. 세부 색·배치와 계획 검토는 [V0.2-PLAN.md](V0.2-PLAN.md)에 남겼다.


v0.2.2 PC 대화 화면: 높이 560px 이상에서 좌우 대화·답변 예시를 창 안에 고정한다. 진행 확인과 메모는 오른쪽을 전환해 보고, 대화 기록은 왼쪽에서 유지한다. 기본 예시는 짧게 미리 보고 선택한 문장의 전체 내용을 확인한다. 4개 예시를 한 번에 펼쳐 읽을 수도 있다. 보내기는 항상 화면 안에 두며 과거 대화·아주 긴 문장·메모만 해당 영역 안에서 스크롤한다. 낮은 창과 모바일, 신청서·회고는 내용을 잘라 숨기지 않는다.
