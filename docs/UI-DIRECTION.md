# 읽기 쉽고 누르기 쉬운 대화 연습실

## v1.2 점토와 움직임(지금의 겉모습)

- 겉모습: 3D 대화실의 점토 인형과 같은 재료. 둥근 면(카드 22px·작은 것 14px), 위는 밝은 테두리·아래는 살짝 눌린 두 겹 그림자(--clay), 누르면 크기 .97과 눌린 그림자(--clay-in). 자리를 바꾸는 움직임은 쓰지 않음.
- 움직임 규칙(public/motion.js, app.css 끝의 v1.2 묶음): 누름 140ms · 바뀜 220ms · 들어옴 420ms · 나감 260ms, 하나의 용수철 곡선. 원인과 결과가 있을 때만(보냄→날아감, 답→튀어나옴, 체크→톡, 준비됨→빛남, 앞/뒤 화면→왼/오른쪽). 동작 줄이기에서는 끔. 애니메이션 끝을 기다려 상태를 바꾸지 않음. 화면 전환은 View Transitions(누르기를 막지 않음).
- 검토 근거: ui-ux-pro-max 지침의 접근성·누르기(44px)·움직임(spring, exit-faster-than-enter, shared-element, interruptible, no-blocking)·한글 IME Enter. 제안된 색(남색·주황)과 글꼴(Baloo·Comic Neue)은 한글이 없고 주제(학교폭력 관계회복)에 비해 너무 어린 느낌이라 쓰지 않았습니다.

## 이전 방향(v0.9까지, 기록으로 남김)

대상은 디지털 기기에 익숙하지 않은 관계회복지원단 교사. 사용자가 요청한 큰 글자, 채워진 면, 부드러운 동작과 기기별 화면을 우선한다.

색: 바탕 #f3f5f8, 글자 #203b37, 초록 #235b4e, 연초록 #e3efde, 연보라 #ece8f7, 살구 #ffeadb. 선 대신 색 면과 간격으로 구획한다. 선택된 질문은 진한 초록 면, 체크와 ‘선택됨’ 글자로 표시한다.

글자: 한국어 시스템 고딕 하나로 통일. 본문 18px, 대화 19px, 제목 26–44px, 보조 정보도 14px 이상. 기본 두께 500, 제목·버튼 700 이상. 글자 크게 기능은 상대 단위로 전체를 확대한다. 읽기와 클릭에 필요한 문장은 왼쪽 정렬.

PC: 왼쪽 메뉴 / 대화창 / 답변 예시를 나란히 둔다. 대화 화면을 창 높이에 맞추고 보내기 버튼을 항상 보이게 한다. 진행 메모는 오른쪽 예시 영역과 전환하며 기록·종료 기능은 제목 옆에 둔다.

모바일·태블릿: 아래쪽에 이름이 있는 고정 탐색. 연습 안에서는 ‘대화 연습 / 진행 확인’을 나눠 한 가지 일에 집중한다. 질문은 1열, 대화와 입력은 같은 화면 흐름에 배치하고 진행 확인을 마치면 대화로 돌아온다. 글자 확대·AI 설정은 상단에서 접근한다.

초기 계획을 검토하여 단순히 모든 카드를 둥글게만 만드는 방향 대신, 관계회복 모임의 생성 삽화·참여자별 말풍선·선택할 발문에 색을 집중한다. 화면 크기를 줄이는 것에 그치지 않고 모바일의 진행 메모 위치와 탐색 방식을 바꾼다.

움직임은 사람의 조작에 답한다. 버튼 누름, 선택 표시, 창 열기, 새로운 발화, 단계 변경만 짧고 부드럽게 움직인다. 입력 중 전체 화면이 다시 움직이지 않도록 변경 범위를 구별하며 운영체제의 동작 줄이기를 따른다. 키보드 초점은 선으로 명확히 남긴다.

신청서는 읽은 뒤 버튼 하나로 사전모임에 이동한다. 추가 체크나 검토 선택 없이 PC·모바일 모두 문서를 한 흐름으로 보여 준다. 사전모임에서는 ‘대화모임 안내 → 무슨 일이 있었니?’ 두 순서를 큰 색 면으로 표시한다. 학생마다 순서를 따로 기억하고, 안내를 보낸 뒤에는 경험을 듣는 질문으로 바뀐다. 학생 얼굴은 학교급별 2명, 주제 삽화는 7종을 재사용하며 역할과 외모를 고정하지 않는다.

## v0.2 고도화

첫 화면은 가상 대화 삽화와 이어갈 연습을 중심으로 배치한다. 연습에서는 현재 저장 상태, 전체 대화 열기, 다음 단계에 필요한 확인 항목을 눈에 띄는 면으로 연결한다. 모바일은 진행 확인 열기로 필요한 위치까지 이동한다. 회고는 실제 질문 장면을 읽고 다음 발문을 생각하도록 구성한다. 세부 색·배치와 계획 검토는 [V0.2-PLAN.md](V0.2-PLAN.md)에 남겼다.


v0.2.2 PC 대화 화면: 높이 560px 이상에서 좌우 대화·답변 예시를 창 안에 고정한다. 진행 확인과 메모는 오른쪽을 전환해 보고, 대화 기록은 왼쪽에서 유지한다. 기본 예시는 짧게 미리 보고 선택한 문장의 전체 내용을 확인한다. 4개 예시를 한 번에 펼쳐 읽을 수도 있다. 보내기는 항상 화면 안에 두며 과거 대화·아주 긴 문장·메모만 해당 영역 안에서 스크롤한다. 낮은 창과 모바일, 신청서·회고는 내용을 잘라 숨기지 않는다.


v0.2.3 질문 컨트롤: PC의 짧은 미리보기·별도 선택 문장 패널을 전체 문장 카드 목록으로 대체한다. 글자 크기(18px, 확대 21px)를 줄이지 않고 높이와 줄바꿈으로 맞춘다. 선택 탭·카드에는 진한 초록 #24594f와 흰 글자, 선택 전 카드에는 흰 면 #fff와 경계 #73877f를 사용한다. 입력 영역은 차분한 회청색 #e3e9ed, 본문은 짙은 초록 #203e39다. 기존의 따뜻한 삽화와 면 중심 디자인은 유지한다. 한 열의 전체 문장을 왼쪽 정렬하고 선택 후에도 크기를 접거나 내용을 숨기지 않는다. 긴 목록은 영역 안에서만 이동하고, 대화와 보내기는 계속 보인다.


v0.2.4 문항 네 개를 2×2 격자로 복원한다. 진한 초록 선택 면과 흰 카드, 회청색 입력 영역은 유지한다. 카드에는 최대 12자의 제목 미리보기와 ‘문장 보기’를 표시하며(긴 제목은 단어 경계 우선), 원래 제목과 문장 전체는 클릭한 상세 창에 표시한다. 카드 글씨만 15px/확대 16px, 낮고 좁은 PC는 14px를 사용한다. 상세 문장·대화·주요 버튼은 기존 큰 글씨를 유지한다. 전체 문장을 읽고 선택을 확정한 뒤 전송하며, 모달 닫기·Escape는 기존 선택을 바꾸지 않는다. 효과음은 짧은 사인파로만 만들고 상단의 눌림 상태·이름이 있는 소리 버튼으로 제어한다.


v0.3.0 초심자용 분류: 사례 목록은 난도별(입문·중급·심화) 묶음으로 보여 주고 입문을 먼저 둔다. 난도는 색과 함께 점 1–3개로 표시해 색에만 의존하지 않는다. 갈등 주제 7개는 고정 색(연한 면 + 진한 글자)을 쓰고 필터 칩·카드 칩·카드 위 띠에 같은 색을 반복해 색만 보고도 주제를 알아보게 한다. 카드는 그림·주제·학교급·제목·난도만 남기고 요약문은 상세 창으로 옮긴다. 모바일은 96px 그림을 왼쪽에 둔 가로형 카드로 목록 길이를 줄인다. 질문 카드는 네 가지 색 띠로 구별하고 넓은 PC 창에서만 번호를 붙이며, 카드 제목 크기는 v0.2.4 기준을 유지한다. 모든 팝업은 Escape와 바깥 배경 클릭으로 닫는다.


## v0.4 따뜻한 연습 스튜디오와 3D 대화 장면

방향: 교사가 학생과 마주 앉아 이야기하는 느낌. 연습실의 중심을 말풍선 목록에서 **무대**로 옮긴다. 자세한 설계는 [v0.4 설계](superpowers/specs/2026-11-19-modern-ui-3d-dialogue-design.md).

색과 면: 바탕은 따뜻한 종이색 #f7f5f0에 세이지·살구·연보라의 아주 옅은 빛 번짐. 정보는 흰 카드(모서리 20–28px, 겹겹의 부드러운 그림자)에 담고, 선 대신 면과 간격으로 나눈다. 기본색은 깊은 숲 초록 #1e4d43. 갈등 주제 7색과 난도 점은 유지한다. 선택 상태는 진한 초록 면 + 흰 글자 + "선택됨" 글자를 그대로 쓴다.

글자: Pretendard Variable(저장소에 포함, 필요한 글자 묶음만 받음). 본문 18px, 크게 21px. 큰 제목은 굵고 자간을 좁힌다.

탐색: PC는 왼쪽 사이드바 대신 위쪽 반투명 앱 바(로고 · 알약 탭 · 효과음·글자 크게·AI 연결). 연습실에서 무대와 질문 카드가 가로 폭을 다 쓰게 하려는 것이다. 휴대전화·태블릿은 아래 고정 탐색을 반투명 막대로 다듬고, 위 막대는 함께 스크롤된다. 대화창은 PC에서 가운데 카드, 휴대전화에서 아래에서 올라오는 시트.

무대: 3D 대화실(점토 인형 캐릭터, 원탁, 창빛). 위쪽에 얼굴 버튼(대화 상대)과 사전모임 순서, 무대 오른쪽 위에 자막 넘기기·목소리·그림 무대 버튼, 아래쪽에 자막. 무대는 장식으로 숨기고(aria-hidden) 정보는 자막과 대화 기록이 전한다. 감정 이름은 보이지 않는다. 3D를 쓸 수 없으면 같은 자리에 그림 무대가 들어간다.

PC 연습실: 창 높이 560px 이상에서 페이지 전체 스크롤 없음. 왼쪽 칸은 무대(약 70%)와 대화 기록(최소 110px), 오른쪽 칸은 2×2 질문 카드와 보내기. 넓고 낮은 무대에서도 얼굴이 잘리지 않도록 카메라 세로 화각에 하한을 둔다.

휴대전화 연습실: 얼굴 버튼(가로 스크롤) → 무대(폭에 맞춘 16:10, 최대 화면 높이 45%) → 대화 기록 → 질문. 대화로 이동하면 기록이 화면 위에서 8px 떨어져 보인다.

움직임: 캐릭터는 듣기 → 생각하기(약 0.7초 뒤) → 말하기 순서로 반응하고, 답이 곧바로 와도 1.3초의 틈을 둔다. 동작 줄이기에서는 카메라 이동과 흔들림을 끄고 자막을 한 번에 보여 주며 깜빡임·입 움직임만 남긴다. 화면 전환은 짧은 페이드를 유지한다(View Transitions는 비동기 갱신이라 쓰지 않음).


## v0.5 2등신 캐릭터와 살아 있는 화면

캐릭터: 머리 하나에 몸 하나(2등신). 팔은 팔꿈치 마디 없이 한 덩어리, 몸통은 콩 모양, 목 없이 큰 머리. 눈은 얼굴 아래쪽에 크게. 머리카락은 둥근 덩어리를 쓰지 않고, 머리 모양을 따라 붙는 얇은 층을 겹쳐 가는 가닥 끝(길이가 조금씩 다름)으로 끝낸다. 가구는 낮은 찻상과 둥근 안락의자, 의자 색은 피부색과 헷갈리지 않는 세이지·연보라·하늘색.

살아 있는 느낌: 캐릭터가 마우스를 따라 보고(말하는 중에는 말하는 사람을 봄), 선생님이 쓰거나 고르는 동안 몸을 기울여 듣는다(2.5초 조용하면 원래대로). 무대 테두리는 상태에 따라 빛난다.

첫 화면: PC에서는 3D 대화실이 첫 카드를 가득 채우고, 왼쪽의 옅은 유리 그라데이션 위에 문구를 띄운다. 3D를 못 쓰면 같은 자리에 삽화가 보인다. 사례 카드는 마우스를 따라 최대 4° 기울고 빛이 스치며, 화면이 바뀔 때만 차례로 떠오른다(검색 입력 중에는 다시 떠오르지 않음). 바탕의 오로라는 38초 주기로 천천히 흐른다. 동작 줄이기에서는 기울기·떠오르기·오로라를 모두 멈춘다.


## v0.6 토킹피스

콘셉트: 관계회복 모임에서는 토킹피스를 쥔 사람만 말하고 나머지는 듣는다. 화면도 같은 약속을 지킨다. 노란 조약돌(#ffc83d, 살짝 비뚤어진 둥근 모양)은 "지금, 여기, 내 차례"에만 놓는다: 지금 있는 메뉴, 지금 단계, 질문을 건넬 사람, 고른 질문, 말하는 캐릭터(무대 테두리와 자막 이름 앞), 이어서 할 연습, 신청서를 읽은 뒤 사전모임 시작 버튼. 다른 곳에는 쓰지 않는다.

색: 바탕 안개색 #e8edeb, 판 흰색, 글자와 주요 버튼 잉크색 #172033, 보조 글자 #3b475b·#566174. 학생·보호자는 대화실에서 앉은 의자 색을 따른다: 피해 경험 학생 세이지 #a9c4a2, 행동한 학생 연보라 #b8afd9, 보호자 하늘 #a7c3d6(옅은 색은 말풍선과 칸 바탕). 이전의 종이색 바탕과 숲 초록은 쓰지 않는다.

글꼴: Pretendard 한 가지. 제목은 굵기 780–830에 자간을 좁혀(−0.035~−0.055em) 글자 자체가 화면의 인상이 되게 한다. 대문자 꼬리표나 한 단어만 색칠하는 강조는 쓰지 않는다.

버튼: 점토 캐릭터와 어울리게 눌리는 키. 판은 그림자 대신 1px 선, 누르는 것만 아래 턱(0 3px 0)이 있고 누르면 3px 내려앉는다. 주요 버튼은 잉크색, 보조 버튼은 흰색과 선, 조용한 버튼은 바탕 없이 글자만. 초점은 잉크색 3px 선(어두운 바탕에서는 조약돌색).

틀: PC는 왼쪽 잉크색 레일(96px)에 로고·메뉴·도구. 연습실은 제목·단계 트랙·버튼을 넓은 화면에서 한 줄, 좁으면 두 줄로 두고 나머지 높이를 무대와 대화에 준다. 휴대전화는 위 작은 막대와 아래 잉크색 탭.

화면별: 첫 화면은 대화실 무대가 가득 차고, 문구는 선생님이 들고 갈 질문 카드처럼 무대 위에 놓인다(휴대전화는 무대 아래 겹침). 사례 카드는 신청서 파일처럼 갈등 주제 색 탭이 위로 튀어나온다. 연습 순서·연습 단계·가이드의 네 모임은 실제 순서라 번호와 이어지는 선으로 잇는다. 질문 카드는 번호, 제목, 질문 미리보기(되짚는 앞부분은 빼고). 내 말은 오른쪽 잉크색 말풍선. 휴대전화 무대는 정사각형이고 자막은 장면 아래 고정 띠.

움직임: 화면이 바뀔 때 사례 카드가 한 번 차례로 놓이고, 누를 때 버튼이 내려앉는 것만 남긴다. 카드 기울기·흐르는 오로라·버튼 빛 효과는 뺐다. 동작 줄이기에서는 모두 멈춘다.


## v0.7 움직임과 크기

움직임 원칙: 무엇이 바뀌었는지 보여 줄 때만 움직인다. 화면 하나에 한 번의 장면만 둔다.
- 화면 전환: 메뉴 순서(사례 → 연습 → 기록 → 가이드)를 따라 앞으로 가면 오른쪽에서, 돌아가면 왼쪽에서 28px 미끄러져 들어온다(0.38초).
- 첫 화면: 무대가 밝아지고(0.9초) → 문구 카드가 올라오고 → 토킹피스가 카드 모서리에 떨어지고 → 연습 순서의 점선이 그어진다. 첫 화면의 유일한 장면.
- 단계 전환(연습실의 한 장면): 토킹피스가 이전 단계 자리에서 다음 단계 자리로 포물선을 그리며 넘어가고, 무대에 장 제목(번호 조약돌 · 단계 이름 · 한 줄 설명)이 2초 동안 떴다 사라진다. 장 제목은 누르기를 막지 않고, 그동안 3D 그리기를 쉰다. 3D 장면을 새로 앉히는 무거운 일과 겹쳐도 건너뛰지 않도록 효과는 화면이 한 번 그려진 뒤 시작한다.
- 대답에 반응하는 움직임: 말풍선은 말한 쪽에서 들어온다(내 말 오른쪽, 학생 왼쪽). 질문 카드를 고르면 톡 튀고, 보내기 버튼 둘레에 노란 고리가 두 번 퍼진다. 얼굴 버튼이나 캐릭터로 대상을 바꾸면 고른 얼굴 버튼이 톡 튄다. 대화창은 누른 자리에서 커진다(PC). 휴대전화는 아래에서 올라오는 시트.
- 소리: 본·사후모임으로 넘어갈 때만 짧은 세 음(도·미·솔). 효과음을 끄면 나지 않는다.
- 동작 줄이기: 모든 CSS·스크립트 움직임과 대화창 뒤 흐림의 나타남까지 끈다.

크기 기준(PC): 누르는 곳은 높이 44px 이상(주요 버튼 54px, 얼굴·무대·탭·메뉴 48px 이상). 글자는 본문·말풍선·자막 18px(크게 21px), 꼬리표 등 보조 글자도 13px 이상. 질문 카드 제목은 15–17px, 미리보기는 카드 크기에 따라 14.5–17px.

## v0.8 다시 해 보기와 손에 잡히는 대화실

연습 도구 원칙: 틀린 질문을 지우는 것이 아니라 다시 해 보게 한다. 지운 질문은 회고에 남겨 처음 말과 지금 말을 견주게 한다.
- 키보드(PC): 숫자 1–4는 카드를 누르는 것과 같다(문장 창이 열리고 "이 문장 선택하기"에 초점). 고른 뒤 Enter는 보내기. 카드 왼쪽 위의 번호가 키 번호다. 안내는 한 줄(`1–4 고르기 · Enter 보내기 · Esc 닫기`)로 문장 보기 안내 옆에 둔다.
- 방금 질문 다시 해 보기: 대화 기록 바로 아래(대화 기록의 알림 영역 밖이라 답마다 읽히지 않음), 흰 바탕 단추와 "답을 지우고 다른 말로 물어봐요". 휴대전화에서는 설명을 숨긴다.
- 장면 다시 보기: 회고에서 무대는 처음부터 두지 않고, 단추를 누르면 창으로 연다(PC는 넓은 창, 휴대전화는 아래에서 올라오는 시트). 상태 한 줄("장면을 다시 보고 있어요." → "다 봤어요.")과 "대사 글로 읽기".
- 인쇄: 종이에서는 잉크색 면을 테두리로 바꾸고(잉크 아끼기), 머리말에 사례·조건·날짜, 카드는 두 칸, 카드·말 하나가 쪽 사이에서 잘리지 않게 한다.

대화실 그래픽(폭주 구구단 1.2의 방식): "손에 잡히는 점토 방"을 목표로, 물건마다 결을 주고 바닥에 붙인다.
- 질감은 모두 캔버스에 그린다(파일을 받지 않음). 같은 씨앗이면 같은 그림이라 사진 비교가 된다.
- 바닥에 붙이기: 가구 밑에 부드러운 접지 그림자. 그림자 지도를 꺼도 남는다.
- 햇빛: 창은 밝게 빛나 빛 번짐을 만들고, 빛줄기는 가산 혼합으로 아주 옅게(불투명도 0.15 안팎), 먼지는 천천히 떠오른다. 동작 줄이기에서는 멈춘다.
- 반사: 이 방을 본뜬 작은 장면을 구워 니스·유약·눈동자에 창이 비치게 한다.
- 화질 단계: 해상도 → 요철·코팅 → 그림자 → 빛 번짐·빛줄기·먼지. 느린 기기의 그리는 속도는 v0.7과 같게 유지한다.

v0.8.1 다듬기:
- 의자 색: 역할 색은 의자 둘레 테에 두고, 앉는 천은 그 사람의 옷과 한눈에 다른 색(ΔE 28 이상)으로 고른다. 사람이 의자에 묻히지 않게 하는 것이 역할 색보다 먼저다.
- 팔: 덧붙인 조각 없이 한 조각 소매(어깨는 몸통 속, 손목은 소매가 부풀어 소맷부리). 몸과 팔은 숨·손짓에 함께 움직인다.
- 빛: 해는 창 하나. 그림자는 선생님 쪽으로, 얼굴은 앞의 부드러운 빛으로, 따뜻한 스탠드가 반대쪽 구석을 채운다.

## v0.9 휴대전화 연습실 한 화면

원칙: 휴대전화에서 연습은 앱 하나의 화면이다. 페이지는 스크롤하지 않고, 대화 기록만 안에서 스크롤한다. 질문을 고르는 동안에도 대화가 보여야 한다.
- 위에서 아래로: 맨 위 한 줄(← · 제목 · 저장 · 마치기 · ⋯) → 단계 점과 진행 확인 → 얼굴 → 무대(약 19%) → 대화 기록(나머지 전부) → 질문 칸.
- 카드를 누르면 바로 고른다(창 없음). 카드 자리가 고른 문장과 [다시 고르기][이 문장 보내기]로 바뀌어, 대화 기록의 높이가 변하지 않는다.
- 자주 쓰지 않는 도구와 앱 메뉴는 연습 중 ⋯ 메뉴로 모은다. 무대 자막은 대화 기록과 같으므로 휴대전화에서는 생략한다.
- 누르는 곳은 48px 이상(보내기 52px), 아주 작은 화면에서는 무대를 먼저 줄인다.
