# v0.2.0 구현 계획과 PRD 점검

상태: 구현 및 로컬 검증 완료. 결과는 PRD-COVERAGE.md와 VERIFICATION.md에 기록.

## 대조 결과

PRD의 사례 30개, 신청서에서 바로 사전모임 진입, 안내 후 사건 듣기, 대상별 사전 대화 분리, 사전·본·사후, 네 가지 조건, 객관식·음성·직접 입력, 세 AI 서비스, 오류 복구, 이미지, 큰 글자·모바일 분리는 구현되어 있다. v0.2에서는 빠진 독립 기능이 있다고 과장하지 않고 다음 완성도를 보완한다.

- 저장·재개: 대화와 진행 항목은 보관되지만 작성 중인 문장과 고른 질문은 복원되지 않는다. 상대·단계별 초안과 현재 발문 방식을 수동 저장에 포함한다.
- 기록 내려받기: 대화·합의·개인 회고는 있으나 화면의 AI 회고/체험 회고가 빠져 있다. 현재 회고와 근거 장면도 내보낸다.
- 진행 확인: 다음 단계 버튼이 비활성인 이유를 구체적으로 알기 어렵다. 실제 미확인 항목과 남은 기록을 안내한다.
- 대화 유지: 지난 단계의 대화는 남아 있지만 종료 전에는 전체를 읽기 어렵다. 진행 중에도 교사가 전체 대화를 열어 볼 수 있게 한다. AI에 전달하는 사전면담 격리는 유지한다.

## 디자인 계획

관계회복 교사의 연습 책상. 첫 화면은 가상 학생 삽화와 연습 이어가기로 진입하고, 연습 화면은 인물의 발언에 시선이 모이도록 만든다.

- 색: 소나무 #235b4e / 잎 #e3efde / 라벤더 #ece8f7 / 살구 #ffeadb / 종이 #f3f5f8 / 먹 #203b37. 색 면은 행동·학생 역할·진행 상태를 구별한다.
- 글자: Apple SD Gothic Neo, Noto Sans KR, Malgun Gothic의 한국어 고딕. 본문 18px, 대화 19px 이상, 제목 28–46px. 제목은 짧게, 설명은 왼쪽 정렬. 확대 글자 지원.
- PC: 삽화가 있는 시작 면 → 이어갈 연습 → 필터·사례. 연습에서는 현재 목표·저장 상태, 대화와 발문, 오른쪽 다음 단계 준비를 함께 본다.
- 모바일: 하단 탐색을 유지하며 대화/진행 확인을 분리한다. 선택한 발문은 대화창에서 확인 후 전송한다. 진행 상태에서 필요한 확인 화면으로 바로 이동한다.
- 움직임: 선택·대상 전환·저장·다음 단계 등 사용자의 행동을 연결하는 짧은 움직임. 입력 중 흔들림, 반복 장식 애니메이션 없음. 동작 줄이기 적용.

검토: 카드 수나 장식 통계만 늘리는 방식은 피한다. 새로운 면은 이어갈 연습, 저장 상태, 단계 준비처럼 실제 행동과 연결되는 곳에만 쓴다. 기존 가상 학생 이미지와 역할별 말풍선을 시각적 중심으로 유지한다.

## 범위

v0.2.0, PRD 적용표·변경 기록·GitHub 자동 검사 추가. 앱만 독립 저장소로 발행하며 상위 개인 조사 원문은 포함하지 않는다. 로컬 앱의 API 키 정책과 수동 저장은 유지한다. 웹 공개 배포·계정·클라우드 동기화는 추가하지 않는다.
