# 다시, 대화 — 관계회복 진행자 연습실

충남 관계회복지원단 교사가 가상 신청서를 읽은 후 학생·보호자와 사전·본·사후모임을 연습하는 로컬 웹앱. 조사 보고서의 동의·안전·영향·책임·이행 점검 원칙을 바탕으로 하며 공식 연수 인증·학생 평가 도구가 아니다.

## 첫 버전의 완료 조건
- 독립적인 가상 사례 30개. 학교급·주제·난도 검색/필터.
- 신청서 확인: 사례별 가상 배경·학생 상황·서류 상태·안전 우려를 읽고 버튼 하나로 사전모임 이동. 추가 체크나 결정 없음. 이전 검토 기록 호환.
- 사전모임은 대상별로 모임 안내 후 있었던 일 듣기. 안내·이야기용 객관식 문장, 직접 입력·음성 입력 지원. 안내 전송 성공 후 이야기 질문으로 전환하고 실패 시 유지.
- 생성한 학생 캐릭터 6명 및 주제 삽화 7장. 학교급별·주제별 공유 자산으로 사용하고 실제 인물·사건과 구분.
- 사전 개별면담(학생별, 보호자), 본모임, 사후모임. 대화 및 합의가 단계 사이에 유지됨.
- 협력 / 방어·교착 / 안전 위협 / 약속 미이행 조건. 성공·부분 진전·교착·중단·미이행 모두 연습.
- 한국어 마이크 입력 → 텍스트 확인·수정 → 수동 전송. 미지원·권한 거부·네트워크 오류 안내.
- 기본 발문 방식은 객관식 질문 선택. 학생·보호자의 직전 답변을 바탕으로 다음 발문 4개(AI 생성 또는 발언 참고 예시)를 제시하고, 추가로 단계·상대·조건별 기본 질문 4개를 볼 수 있음. 선택 후 전송·문장 수정·직접 입력·마이크를 선택할 수 있음. 상대·단계가 바뀌면 이전 선택을 해제하고 전송 실패 시 선택은 유지함.
- Claude, Gemini, OpenAI의 사용자 직접 API 키 입력 및 연결 확인. 키는 브라우저 메모리와 요청 처리 중에만 보유. 저장·로그·내보내기에 포함하지 않음.
- API 없이 작동하는 시나리오 체험. 실제 AI와 분명히 구별, API 실패시 몰래 체험 응답으로 바꾸지 않음.
- 코치 질문, 진행 체크, 종료 회고, 대화 기록 저장·재개·다운로드·삭제.
- 합의 성사율을 성공 점수로 삼지 않음. 적절한 보류·중단도 보호를 위한 성과. 결과 판정은 연습용 피드백.

## 화면 방향
팔레트: 초록 #235b4e, 연초록 #e3efde, 연보라 #ece8f7, 살구 #ffeadb, 바탕 #f3f5f8, 글자 #203b37. 시스템 고딕의 굵은 제목과 기본 18px 본문을 사용한다. 경계선 대신 넓은 색 면, 큰 버튼, 여백으로 구획한다. 글자 확대와 동작 줄이기를 지원한다.

PC에서는 왼쪽 탐색, 중앙 사례·대화, 오른쪽 진행 노트. 900px 이하에서는 아래쪽 탐색과 ‘대화 연습 / 진행 확인’ 전환으로 화면을 분리한다. 따뜻한 입체 애니메이션풍의 가상 인물·상황 삽화를 사용하고, 질문 선택·새로운 발화·단계 이동·창 열기에 짧은 움직임을 사용한다. 상세 방향은 [UI-DIRECTION.md](UI-DIRECTION.md)에 기록했다.

## 범위와 데이터
공유·계정·배포·실제 학생 데이터 수집은 이번 범위 밖. 작성된 사례는 모두 가상. 대화 기록은 사용자의 저장 동작으로 이 브라우저 localStorage에 보관. API를 켜면 선택한 제공사로 사례·대화·합의가 전송됨. 음성은 브라우저의 인식 서비스 정책 적용. 모델명은 사용자가 수정 가능.

구조는 Node 기본 모듈 HTTP 서버 + 브라우저 ES modules. 설치 의존성을 없애 실행 단계를 줄인다. 외부 AI 호출은 동일 출처의 로컬 서버가 중계하며 서버는 루프백 주소에만 바인딩한다.

## AI 오류와 다음 발문 개선

- 서비스별 HTTP 원인을 구분하고 인증·결제·한도 오류에는 반복 요청하지 않음. 일시적인 5xx 오류는 60초 전체 제한 안에서 한 번만 재시도. 오류 원문·키는 노출하지 않음.
- 역할 대사와 함께 teacherChoices 4개를 생성. 직전 학생 발언을 반영하고 상대·단계·자발성을 고려하도록 요청. 선택지가 누락되거나 형식이 잘못되어도 유효한 학생 대사는 보존하고 발언 참고 예시로 보완.
- 모바일에서는 선택 즉시 대화창으로 부드럽게 이동. 대화창 아래 선택 문장 확인·다시 고르기·전송 버튼 제공. 전송 후 최신 응답으로 이동. PC 선택은 화면을 이동하지 않음. 동작 줄이기 설정 존중.
- 선택지만으로 자동 전송하지 않으며 실패 시 원래 선택·직접 입력·안내 순서를 유지. 사전 대화와 다음 선택지는 학생별로 분리하고 기록 저장·재개를 지원.

핵심 기능을 대조하고 기록·회고·진행 안내를 보완했다. 첫 화면 이어가기, 상대별 초안·선택 저장, 수동 저장 상태, 다음 단계 준비 안내, 진행 중 전체 대화, 회고 근거 장면과 내보내기를 포함한다. 세부 확인 결과는 [PRD-COVERAGE.md](PRD-COVERAGE.md), 변경 내역은 [CHANGELOG](../CHANGELOG.md)를 따른다. 수동 저장과 API 키 비저장 정책은 유지한다.
